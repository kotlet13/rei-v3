# Emocio VWM E2: LPWM technical-overfit gate

This research package freezes and executes one from-scratch technical-overfit
test of the unmodified LPWM candidate at commit
`4cf53c403433e64c01652ac2adbec66231a46dea`.

The E2 claim is intentionally narrow. A pass is technical-overfit evidence on
twelve authored visual episodes only. It is not evidence of social
generalization, a working Emocio, an autonomous desire, semantic understanding,
or readiness for the active REI runtime.

The frozen training tree remains in the isolated external LPWM environment.
Only its complete file manifest, byte hashes, protocol, adapter, tests, and
eventual result evidence are committed here. The model receives RGB tensors
only: six observation frames and, for the image-goal condition, the exact
terminal frame of that same authored trajectory.

The prerequisite E1R medium review passed on attempt 3. That pass establishes
only that the deterministic 128 x 128 laboratory medium is readable enough for
this gate; it does not establish LPWM model fit or a working Emocio. E2 is one
pre-registered run, not a sweep. The frozen protocol forbids threshold changes,
model substitution, post-freeze dataset regeneration, and semantic inputs.
